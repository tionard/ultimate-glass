# Ultimate Glass 0.1.1

Initial public release of Ultimate Glass for Minecraft Java 26.2 on Fabric.

## Highlights

- Place clear and stained glass panes along block edges.
- Rotate edge panes with the Glazier's Tool.
- Toggle panes between edge and centred placement.
- Collect glass blocks and panes intact.
- Includes the updated mod icon, Glazier Point Driver texture, and any-ingot crafting recipe.
