# Ultimate Glass

A Fabric mod for Minecraft Java 26.2 that expands glass-pane placement and adds a dedicated glassworking tool.

## Planned features

- Place vanilla and stained glass panes on block edges as well as in the vanilla centered position.
- Rotate placed edge panes.
- Toggle panes between edge and centered modes.
- Collect glass blocks and panes intact with the Glazier's Tool.
- Server-authoritative interactions with client-side controls and Mod Menu integration.

## Status
